How Announce Check handles data.

Announce Check has no accounts, analytics, tracking pixels, cookies, or hosted test service. The CLI does not send reports, transcripts, form values, or target URLs to us.

Local files

The CLI reads your local configuration and expected transcript. It writes a local HTML report unless you pass --no-report.

--update writes observed events to the expected transcript. Filled form values are redacted from observed event text and errors.

Website storage

The site caches public pages and assets for offline reading. The demo does not store form input or personal information.

Remove the public cache with your browser’s site-data controls.

Your target application

Your chosen website may have different privacy practices. Loopback targets work by default. Remote targets require an explicit authorization flag.

Only test systems you own or have permission to test.

Contact

For privacy questions, open an issue in the public source repository.
